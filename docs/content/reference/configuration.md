douban aims to need almost no configuration. As you add settings,
document each one here with its default.

## Global flags

| Flag | Meaning |
|---|---|
| `--help` | Help for any command |
| `--version` | Print the version |

## Environment variables

None yet. Add them here as the tool grows, prefixed `douban_` in upper
case (for example `douban_TOKEN`).

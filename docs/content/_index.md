Crawl Douban (豆瓣) books and movies into structured JSON

```bash
douban search python         # cross-category search
douban book 1084336          # one book in full
douban top250 --limit 50     # the movie Top 250
douban --help                # the command tree
```

Seven read-only commands over Douban's public pages: `search`, `suggest`,
`book`, `top250`, `chart`, `nowplaying`, and `doulist`. The [CLI
reference](/reference/cli/) is the full surface.
